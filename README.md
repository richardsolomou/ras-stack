# ras-stack workspace

This repository contains the ras-stack package, its application starter, and the project website.

| Workspace                                            | Purpose                                                                           |
| ---------------------------------------------------- | --------------------------------------------------------------------------------- |
| [`packages/ras-stack`](packages/ras-stack)           | The `ras-stack` package, runtime assets, reference application, and documentation |
| [`packages/create-ras-app`](packages/create-ras-app) | The `create-ras-app` command-line package                                         |
| [`apps/web`](apps/web)                               | The ras-stack website                                                             |

Run `just check` from the repository root to validate every workspace.
