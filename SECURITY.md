# Security Policy

## Reporting a vulnerability

Do not open a public issue for an unpatched vulnerability. Use GitHub private vulnerability reporting for this repository. If it is unavailable, open an issue asking for a private contact method without including vulnerability details.

Include the affected version, a minimal reproduction, the impact, and any known workaround. I will coordinate a fix and disclosure timing with you.

## Supported versions

Security fixes are released for the latest npm version. Upgrade to the latest release and confirm the problem still occurs before reporting it.
